
# Diabetes Prediction Model 🩺

## Overview
This project builds a machine learning model to predict the likelihood of diabetes based on patient health data.

## Objective
To support early risk detection using data-driven classification techniques.

## Dataset
Pima Indians Diabetes Dataset

## Workflow
•⁠  ⁠Data cleaning and preprocessing
•⁠  ⁠Exploratory Data Analysis (EDA)
•⁠  ⁠Feature selection
•⁠  ⁠Model training
•⁠  ⁠Model evaluation

## Models Used
•⁠  ⁠Logistic Regression
•⁠  ⁠Random Forest Classifier

## Evaluation Metrics
•⁠  ⁠Accuracy
•⁠  ⁠Precision
•⁠  ⁠Recall
•⁠  ⁠F1 Score
